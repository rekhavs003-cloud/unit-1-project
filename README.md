# Mood Tracker 🌿

A beginner-level React mood and weather journal created for the LaunchCode Unit 1 Front-End React Application project.

## Features

- Home page
- About page
- Mood journal
- Add mood entries
- Edit mood entries
- Delete mood entries
- Mood calendar
- Mood filtering
- Form validation
- React Router navigation
- React state and props
- useEffect
- localStorage persistence
- Responsive design
- Green and cream color theme
- No JavaScript alerts
- No console.log statements

## Run the project

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local Vite address shown in the terminal.

## Main project components

- Header
- Footer
- Button
- MoodForm
- MoodList
- MoodItem
- MoodCalendar

## Pages

- `/` Home
- `/journal` Journal
- `/calendar` Calendar
- `/about` About

## Notes

The public weather API is intentionally not included because it is optional for the project. Weather is selected manually in the form.

localStorage is used to simulate simple data persistence.
